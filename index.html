Project / 01Prototype

GiriGuide

Pilgrim assistance · Web application

GiriGuide is a web application designed to help pilgrims visiting Tiruvannamalai. It provides useful information about temple visits, Girivalam routes, transportation and parking facilities. The application aims to make trip planning easier and more convenient for visitors. We also worked on providing offline access to important map information.

FocusTemple visits, Girivalam routes, transport, parking and offline maps
My contributionReact frontend and offline access to important map information
  • React
  • Offline map access
  • PostgreSQL (pending)

Sentiment Analysis

Natural language processing · Text classification

A sentiment analysis system that identifies the sentiment of text as Positive, Negative or Neutral. It uses Natural Language Processing (NLP) techniques to process and analyse text data, and applies TF-IDF for text feature extraction. The project helps understand opinions and emotions expressed through text.

FocusClassifying text as positive, negative or neutral
